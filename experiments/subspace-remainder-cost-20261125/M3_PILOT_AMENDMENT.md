# Post-start execution amendment

The initial pilot invocation on 2026-11-25 failed every completed worker at its final telemetry line because the script requested the nonexistent `ru_max` attribute rather than `ru_maxrss`. Its per-target query and verification receipts are preserved in `m3_pilot_initial_worker_errors.json` and are excluded from the primary timing comparison. The typo is corrected in the new script hash recorded by the resumed primary run. The frozen input manifest, target panel, relation algorithms, and timeout rule are unchanged. This amendment is recorded after the failed invocation; it does not change the protocol hash or silently overwrite the failed receipts.

The primary runner checked the regenerated input manifest before timing but did not record the wall and CPU time of that common generation step. Consequently the pilot table reports complete **worker** costs and a separately measured common linear-algebra cost, but not a fully common-input-charged total. The missing input timing is a protocol deviation and must be corrected before any full-collection claim. It is common to all three arms on a fixed cell and cannot change their worker-time ordering, but it changes the quoted speedup ratio.
