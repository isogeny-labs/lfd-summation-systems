# Lead 2: the index of Z[π, π̄] in O_K

Status: **proved** (Theorems 1 and 2, Corollaries 1 to 3 below) and **checked numerically**
two independent ways (PARI HNF and SNF, and pure-Python big-integer HNF with mod-p ranks). No
counterexample was found. A Lean formalization was not attempted: neither `lean` nor `lake` nor
`elan` is installed on this host.

## 0. Statement

Let α, β be the roots of x² + x + 2, with α = (−1+√−7)/2. Then α + β = −1, αβ = 2 and
α − β = √−7. Let F = Q(√−7), so O_F = Z[α]. Let ℓ be an odd prime, ζ = ζ_ℓ, and

* Λ_ℓ := O_F ⊗_Z Z[ζ] = O_F[T]/(Φ_ℓ(T)), with z the image of T;
* π := α z, π̄ := β z⁻¹ (so π π̄ = 2), and R_ℓ := Z[π, π̄] ⊆ Λ_ℓ;
* U_n := (αⁿ − βⁿ)/(α − β), so U_0 = 0, U_1 = 1, U_{n+1} = −U_n − 2U_{n−1}, and f := |U_ℓ|.

For ℓ ≠ 7, Λ_ℓ = O_K with K = Q(ζ_ℓ, √−7) (Lemma 0).

**Main Theorem.** For every odd prime ℓ (ℓ = 7 included, with Λ_7 the tensor algebra):

1. [Λ_ℓ : R_ℓ] = |U_ℓ|^(ℓ−2);
2. Λ_ℓ / R_ℓ ≅ (Z/|U_ℓ| Z)^(ℓ−2) as abelian groups, and |U_ℓ| Λ_ℓ ⊆ R_ℓ;
3. ζ_ℓ ∈ R_ℓ ⇔ R_ℓ = Λ_ℓ ⇔ U_ℓ = ±1.

For ℓ ≠ 7 this is the conjectured statement [O_K : Z[π, π̄]] = |U_ℓ|^(ℓ−2), together with
ζ_ℓ ∈ Z[π, π̄] ⇔ U_ℓ = ±1. Part 2 also settles the prime-power question: the local index at p
is p^(v_p(U_ℓ)(ℓ−2)) whatever v_p(U_ℓ) is, and the p-part of the quotient is (Z/p^v)^(ℓ−2),
not a group with more or fewer cyclic factors.

Parts 1 and 2 are special cases of Theorem 2, which holds for any quadratic Lucas pair (s, q)
(the index formula unconditionally, the group structure when gcd(s, q) = 1).

## 1. General setting

Fix s, q ∈ Z with s² − 4q not a square, and let α, β be the roots of x² − s x + q. Let
O := Z[α] = Z ⊕ Zα (an order in the quadratic field Q(α)), let x ↦ x̄ be its nontrivial
automorphism (α ↔ β), and let U_n := (αⁿ − βⁿ)/(α − β) ∈ Z. Fix an odd prime ℓ with U_ℓ ≠ 0
and put f := |U_ℓ|. (For s = −1, q = 2: O = Z[α] = O_F because disc(x²+x+2) = −7 is a
fundamental discriminant.)

Let Γ := O[T]/(T^ℓ − 1) = ⊕_{i ∈ Z/ℓ} O·T^i (a free O-module of rank ℓ, graded by Z/ℓ), let
N := 1 + T + … + T^(ℓ−1), and Λ := O[T]/(Φ_ℓ(T)) = Γ / (Γ·N). Because T·N = N in Γ, Γ·N = O·N.
Write z for the image of T in Λ. Set

* R̃ := Z[αT, βT⁻¹] ⊆ Γ (T⁻¹ = T^(ℓ−1)), and R := Z[αz, βz⁻¹] ⊆ Λ, the image of R̃
  (the image of a ring generated by some elements is the ring generated by their images).

## 2. Lemmas

**Lemma 0** (ambient ring). For ℓ ≠ 7, O_F ⊗ Z[ζ_ℓ] is the ring of integers of the field
K = Q(ζ_ℓ, √−7), and [K : Q] = 2(ℓ − 1). For ℓ = 7 the algebra F ⊗ Q(ζ_7) is not a field.

*Proof.* Only ℓ ramifies in Q(ζ_ℓ), while 7 ramifies in F = Q(√−7). So for ℓ ≠ 7,
F ⊄ Q(ζ_ℓ), hence F ∩ Q(ζ_ℓ) = Q and F ⊗ Q(ζ_ℓ) = K is a field of
degree 2(ℓ−1). The discriminants −7 and ±ℓ^(ℓ−2) are coprime for ℓ ≠ 7, so O_K = O_F · Z[ζ_ℓ] =
O_F ⊗ Z[ζ_ℓ] (Neukirch, *Algebraic Number Theory*, Ch. I, Prop. 2.11). For ℓ = 7,
√−7 ∈ Q(ζ_7), so F ⊗ Q(ζ_7) ≅ Q(ζ_7) × Q(ζ_7). ∎

**Lemma 1** (the determinant pairing). For x, y ∈ O put D(x, y) := (x ȳ − x̄ y)/(α − β). Then
D is Z-bilinear, alternating, Z-valued on O, D(1, α) = −1, and for x = a + bα, y = c + dα
(a, b, c, d ∈ Z), D(x, y) = −(ad − bc). Consequently, if D(x, y) ≠ 0 then
[O : Zx + Zy] = |D(x, y)|.

*Proof.* Bilinearity and D(x, x) = 0 are clear. D(1, α) = (β − α)/(α − β) = −1. By
bilinearity and alternation, D(a + bα, c + dα) = (ad − bc) D(1, α). The last claim is the
determinant formula for the index of a full sublattice of Z². ∎

**Lemma 2** (values). For i, j ≥ 0: D(α^i, β^j) = U_{i+j}, and D(1, α^n) = −U_n.

*Proof.* conj(β^j) = α^j and conj(α^i) = β^i, so D(α^i, β^j) = (α^(i+j) − β^(i+j))/(α − β).
Similarly D(1, αⁿ) = (βⁿ − αⁿ)/(α − β). ∎

**Lemma 3** (the degree-0 ring). Let A := Z[α^ℓ]. Then A = Z + Zα^ℓ = Z + fO, and [O : A] = f.

*Proof.* α^ℓ satisfies X² − V_ℓ X + q^ℓ with V_ℓ = α^ℓ + β^ℓ ∈ Z, so A = Z + Zα^ℓ. Write
α^ℓ = a + bα. By Lemmas 1 and 2, −U_ℓ = D(1, α^ℓ) = b·D(1, α) = −b, so b = U_ℓ and
A = Z + Z U_ℓ α = Z + fO. Its index in O = Z ⊕ Zα is f. ∎

**Lemma 4** (the degree-i lattices). For 1 ≤ i ≤ ℓ − 1 let N_i := Zα^i + Zβ^(ℓ−i). Then
[O : N_i] = f, fO ⊆ N_i, and M_i := Aα^i + Aβ^(ℓ−i) equals N_i.

*Proof.* [O : N_i] = |D(α^i, β^(ℓ−i))| = |U_ℓ| = f by Lemmas 1 and 2 (f ≠ 0). A finite group of
order f is killed by f, so fO ⊆ N_i. Clearly N_i ⊆ M_i. Conversely, by Lemma 3,
Aα^i = Zα^i + fα^i O ⊆ N_i + fO = N_i, and likewise Aβ^(ℓ−i) ⊆ N_i. ∎

**Lemma 5** (grading). Put M_0 := A. Then R̃ = ⊕_{i=0}^{ℓ−1} M_i T^i.

*Proof.* αT and βT⁻¹ commute, so R̃ is the Z-span of the monomials
(αT)^a (βT⁻¹)^b = α^a β^b T^(a−b), a, b ≥ 0. Each is homogeneous, so R̃ = ⊕ R̃_i T^i, where R̃_i
is the Z-span of α^a β^b over a − b ≡ i (mod ℓ). We show R̃_i = M_i. Write a − b = i + kℓ with
0 ≤ i ≤ ℓ − 1.

* k ≥ 0: α^a β^b = q^b α^i (α^ℓ)^k ∈ Aα^i (and ∈ A if i = 0).
* k < 0, i = 0: α^a β^b = q^a (β^ℓ)^(−k) ∈ A, because β^ℓ = V_ℓ − α^ℓ ∈ A.
* k < 0, i ≥ 1: b − a = (ℓ − i) + (−k − 1)ℓ, so α^a β^b = q^a β^(ℓ−i) (β^ℓ)^(−k−1) ∈ Aβ^(ℓ−i).

So R̃_i ⊆ M_i. Conversely A is Z-spanned by the (α^ℓ)^m (β^ℓ)^n (it contains 1 and α^ℓ), and
α^(i+ℓm) β^(ℓn), α^(ℓm) β^(ℓ−i+ℓn) are monomials with a − b ≡ i. So M_i ⊆ R̃_i. ∎

**Lemma 6** (the norm line). ∩_{i=0}^{ℓ−1} M_i = fO.

*Proof.* "⊇": fO ⊆ A (Lemma 3) and fO ⊆ M_i for i ≥ 1 (Lemma 4). "⊆": let x ∈ M_0 ∩ M_1
(here ℓ ≥ 2 is used, so 0 and 1 are distinct residues). By Lemma 3, x = λ + y with λ ∈ Z and
y ∈ fO. As fO ⊆ M_1 = N_1, λ ∈ N_1: λ = mα + nβ^(ℓ−1) with m, n ∈ Z. Pair with α:
D(λ, α) = λ D(1, α) = −λ, while D(mα + nβ^(ℓ−1), α) = n D(β^(ℓ−1), α) = −n U_ℓ (Lemma 2).
Hence λ = nU_ℓ ∈ fZ and x ∈ fO. ∎

## 3. Theorems

**Theorem 1.** [Γ : R̃] = f^ℓ, Γ/R̃ ≅ O/A ⊕ ⊕_{i=1}^{ℓ−1} O/N_i, and fΓ ⊆ R̃.

*Proof.* Lemma 5 and Γ = ⊕ O T^i; the index is f · f^(ℓ−1) by Lemmas 3 and 4; fΓ ⊆ R̃ because
fO ⊆ M_i for all i. ∎

**Theorem 2.** (a) [Λ : R] = f^(ℓ−2) and fΛ ⊆ R.
(b) If moreover gcd(s, q) = 1, then Λ/R ≅ (Z/fZ)^(ℓ−2).

*Proof of (a).* Λ/R ≅ Γ/(R̃ + ON). By the second isomorphism theorem,
[Γ : R̃ + ON] = [Γ : R̃] / [R̃ + ON : R̃] = f^ℓ / [ON : R̃ ∩ ON].
The map O → ON, c ↦ cN = Σ cT^i, is a bijection (Γ is free on the T^i), and by Lemma 5,
cN ∈ R̃ iff c ∈ M_i for every i. So [ON : R̃ ∩ ON] = [O : ∩ M_i] = [O : fO] = f² (Lemma 6), and
[Λ : R] = f^ℓ / f² = f^(ℓ−2). The inclusion fΛ ⊆ R is the image of fΓ ⊆ R̃ (Theorem 1).

*Proof of (b).* Let G := Λ/R, of order f^(ℓ−2) and exponent dividing f by (a). Fix a prime
p | f with v := v_p(f). We show dim_{F_p} G/pG = ℓ − 2.

First, gcd(s, q) = 1 makes α^i primitive in O (α^i ∉ pO) for every i ≥ 0 and every prime p:
the ideal (α, β) contains α + β = s and αβ = q, hence 1. If p | α^i then p | β^i (apply
conjugation), so p divides (α^i, β^i) ⊇ (α, β)^(2i−1) = O, which is impossible.

Now G/pG ≅ Γ/(R̃ + ON + pΓ). By Lemma 5, Γ/(R̃ + pΓ) ≅ ⊕_i O/(M_i + pO). For i = 0,
M_0 + pO = Z + pO (Lemma 3, p | f), and O/(Z + pO) ≅ F_p because 1 ∉ pO. For i ≥ 1,
(M_i + pO)/pO is the F_p-span of α^i and β^(ℓ−i) in O/pO ≅ F_p². Their determinant is
D(α^i, β^(ℓ−i)) = U_ℓ ≡ 0 (mod p), and α^i ≢ 0, so the span is a line and O/(M_i + pO) ≅ F_p.
Hence dim Γ/(R̃ + pΓ) = ℓ. The image of ON in this space is the image of
O → ⊕_i O/(M_i + pO), c ↦ (c mod M_i + pO)_i, whose kernel ∩_i (M_i + pO) contains pO and is
contained in (Z + pO) ∩ (N_1 + pO). That intersection is pO, by the argument of Lemma 6 taken
mod p: if λ ∈ Z and λ = mα + nβ^(ℓ−1) + py with y ∈ O, then pairing with α gives
−λ = −nU_ℓ + pD(y, α) ≡ 0 (mod p). So the image of ON has dimension 2 and
dim G/pG = ℓ − 2.

The p-primary part G_p therefore has exactly ℓ − 2 cyclic factors, each of order at most p^v
(exponent divides f), and order p^(v(ℓ−2)) by (a). So every factor is Z/p^v and
G_p ≅ (Z/p^v)^(ℓ−2). Summing over p | f gives G ≅ (Z/f)^(ℓ−2). ∎

*Remark.* The hypothesis gcd(s, q) = 1 in (b) is needed. For (s, q) = (−5, 10), ℓ = 5,
U_5 = 25: the index is 25³ = 15625 as (a) says, but the Smith form is
Z/25 ⊕ (Z/5)⁴, not (Z/25)³ (`general_tq.out`, lines marked "outside Thm 2(b)"; 234 of the 316
non-coprime cases tested have a Smith form other than (Z/f)^(ℓ−2)). For x² + x + 2, gcd(−1, 2) = 1.

**Corollary 1** (Main Theorem, parts 1 and 2). Take s = −1, q = 2. Then O = O_F, Λ = Λ_ℓ,
R = R_ℓ, and gcd(s, q) = 1. Theorem 2 gives [Λ_ℓ : R_ℓ] = |U_ℓ|^(ℓ−2) and
Λ_ℓ/R_ℓ ≅ (Z/|U_ℓ|)^(ℓ−2), for every odd prime ℓ (with U_ℓ ≠ 0 by Corollary 3(i)). For ℓ ≠ 7,
Λ_ℓ = O_K by Lemma 0.

**Corollary 2** (Main Theorem, part 3). For ℓ ≥ 3: ζ ∈ R ⇔ R = Λ ⇔ f = 1.

*Proof.* If f = 1, R = Λ ∋ z by Theorem 2(a). If z ∈ R, then z⁻¹ = z^(ℓ−1) ∈ R and
α = (αz)·z⁻¹ ∈ R, so R ⊇ Z[α, z] = Λ and f^(ℓ−2) = 1, so f = 1 because ℓ − 2 ≥ 1. ∎

**Corollary 3** (where the index lives, for x² + x + 2).
(i) U_n ≠ 0 for n ≥ 1, and U_n is odd for n ≥ 1.
(ii) For ℓ ≠ 7, 7 ∤ U_ℓ. (iii) ℓ ∤ U_ℓ; more precisely U_ℓ ≡ (−7/ℓ) (mod ℓ) for ℓ ≠ 7.
(iv) Every prime p | U_ℓ satisfies p ≡ (−7/p) = ±1 (mod ℓ).
Hence the index is a unit at 2, at 7 (ℓ ≠ 7) and at ℓ: the only primes with a nontrivial
local index are the primes p | U_ℓ, all ≡ ±1 (mod ℓ), with local index p^(v_p(U_ℓ)(ℓ−2)).

*Proof.* (i) U_{n+1} ≡ U_n (mod 2) and U_1 = 1. If U_n = 0 then (α/β)ⁿ = 1; the roots of
unity of F = Q(√−7) are ±1, and α = ±β is false (α − β = √−7 ≠ 0, α + β = −1 ≠ 0).
(ii) α ≡ β (mod √−7), so U_n = Σ_{k=0}^{n−1} α^k β^(n−1−k) ≡ nα^(n−1) (mod √−7O_F), and α is
a unit mod √−7 (N(α) = 2). So 7 | U_n ⇔ √−7 | n ⇔ 7 | n.
(iii) Standard for Lucas sequences with D = s² − 4q = −7: 2^(ℓ−1) U_ℓ = Σ_k C(ℓ, 2k+1) s^(ℓ−2k−1) D^k
≡ D^((ℓ−1)/2) ≡ (D/ℓ) (mod ℓ), and 2^(ℓ−1) ≡ 1.
(iv) For p | U_ℓ (p odd by (i), p ≠ 7 by (ii)): α^ℓ ≡ β^ℓ (mod 𝔭) for a prime 𝔭 | p of
O_F, and α ≢ β (mod 𝔭) since α − β = √−7 is prime to p. So γ := α/β mod 𝔭 has order exactly ℓ.
If p splits, γ ∈ F_p^× so ℓ | p − 1. If p is inert, O_F/p = F_{p²} and the Frobenius swaps α and β, so
β ≡ α^p and γ ≡ α^(1−p), whence γ^(p+1) = α^(1−p²) = 1 and ℓ | p + 1. In both cases p ≡ (−7/p) (mod ℓ). ∎

## 4. Remarks on the hints in the task

* "Z[π, π̄] = Z[π] + Z[π̄] since ππ̄ = 2": true, since π^a π̄^b = 2^min(a,b) π^(a−b) or
  π̄^(b−a). It is not needed above; the grading of Lemma 5 does the same job.
* "π^ℓ = α^ℓ": this is Lemma 3's ring A = Z[α^ℓ] = Z + |U_ℓ| O_F, which is the degree-0 piece.
* "Prime by prime; p ∤ 2U_ℓ gives equality": Theorem 2(a) is global and needs no localization.
  Primes p ∤ U_ℓ contribute nothing because every M_i contains U_ℓ O (Lemma 6). At p = 2 the
  hint's coprimality of α and β is what gives primitivity in Theorem 2(b); the index statement
  (a) does not use it.
* "Rank ℓ of 2(ℓ−1) mod p": this is the computation dim Γ/(R̃ + pΓ) = ℓ minus the 2-dimensional
  norm line in the proof of Theorem 2(b); equivalently dim (R + pΛ)/pΛ = ℓ.
* "2 not a primitive root mod ℓ": nothing in the proof uses the order of 2 mod ℓ, and the
  numerics (both kinds of ℓ, section 6) agree. For ℓ ≠ 7 the 2(ℓ−1) conjugates σ(α)σ(ζ) of π are
  pairwise distinct (αζ^a = βζ^b would make α/β a root of unity), so π generates K and its
  minimal polynomial has degree 2(ℓ−1) = 2 dim A_ℓ. By Tate's theorem, A_ℓ is then simple over
  F_2 with End⁰(A_ℓ) = K, for every ord_ℓ(2). (This remark is standard background, not used in
  the proof.)

## 5. ℓ = 7

In the tensor algebra Λ_7 = O_F ⊗ Z[ζ_7] the theorem holds: U_7 = 7 and [Λ_7 : R_7] = 7^5,
with quotient (Z/7)^5 (proved, Theorem 2; checked numerically). But Λ_7 is not a domain
(Lemma 0), so it is not O_K for the field. In the field Q(ζ_7) ⊇ Q(√−7), with α identified with
(−1 ± g)/2 where g = ζ+ζ²+ζ⁴−ζ³−ζ⁵−ζ⁶ is the Gauss sum (g² = −7), the ring Z[αζ, βζ⁻¹] has index
**1** in Z[ζ_7] for both signs, so ζ_7 lies in it although U_7 = 7. This is *checked numerically*
only (`index_hnf.out`, last two lines). It does not contradict the theorem, whose ambient ring
for ℓ = 7 is the tensor algebra. Geometrically, π = αζ_7 then has degree 6 over Q, so the
Frobenius characteristic polynomial of the 6-dimensional A_7 is a square, and A_7 is isogenous
to the square of a 3-dimensional variety. ℓ = 7 is excluded from the field statement.
