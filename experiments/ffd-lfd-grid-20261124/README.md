# Frozen FFD/LFD grid certification, 2026-11-24

This campaign reads the paper repository's frozen `experiments/ic-curve-sweep/cases.jsonl`, `systems.jsonl`, and `results.jsonl` as the m=2 grid manifest. There are 3,163 cases, 3,005 distinct systems, and 21 `(n,m,field)` cells: five prime-field cells and sixteen binary/Koblitz cells. Duplicate cases that produce the same polynomial system are counted once. The frozen sweep inputs and audit scripts are stored with the paper repository. The fixed-basis Semaev source inputs and LFD receipts are in this package under `inputs/`.

For the 1,745 binary and Koblitz systems, `run_binary_ffd.py` computed homogeneous FFD under the explicitly stated `F2` square-zero Koszul/Frobenius convention. `audit_binary_ffd.py` independently replayed every saved image and trivial-syzygy rank using integer-bit Gaussian elimination, checked complete manifest coverage, and tied the result to the LFD receipts. Its receipt is `audit-binary-ffd.json`: 1,681 systems have exact FFD, while 64 contain a constant input and have no FFD under this convention. Their LFD values are still exact. Each field cell's full FFD and LFD histogram is in the audit receipt.

For the 1,260 prime systems, `audit_prime_ffd.py` independently reconstructs every normalized S3 generator from the frozen curve, target and coset scale. The kernel-checked theorem `ICFallDegrees.PrimeFieldConclusions.ordinary_ffd` gives exact homogeneous FFD 3 when `3t²+a=0` and 4 otherwise. A nonzero equal coset scale on both free abscissas transports the theorem by dividing S3 by the fourth power of the scale. The source-bound receipt `audit-prime-ffd.json` checks every system, yielding four FFD-3 and 1,256 FFD-4 systems; all saved LFD intervals are singleton.

The separate fixed six-coordinate S3 panel over `GF(2^6)` through `GF(2^11)` contains 1,977 target systems. `run_semaev_ffd.py` saved a homogeneous FFD rank certificate for every target; `audit_semaev_ffd.py` independently replayed all ranks and bound them to the exact LFD/SD receipts. The complete receipt is `audit-semaev-ffd.json`. Homogeneous FFD differs from the previously reported affine first strict fall on 218 GF(2^10) targets. The two conventions must not be pooled.

The original sweep's `--check-only` full LFD regeneration passed on the VM: it regenerated all 3,163 cases and replayed every one of the 3,005 exact result receipts. The saved terminal log is `lfd-sweep-replay-20261124.log` (SHA256 `f3120d9356ac48c8f9bf586ac78515e19d4bf327c11f0260a23329a6f36df140`). This is a fresh end-to-end LFD replay of the frozen m=2 grid.

The separate m=3–6 split-presentation protocol declares seven `(m,k)` cells over specified prime fields. `audit_split_ffd.py` reconstructed all 24 systems in its six completed cells from the frozen records, matched system hashes and exact LFD receipts, and certified FFD exactly 4. The degree-3 input has nonzero top form; its two square-zero chain terms have an explicit degree-4 annihilator, and Koszul rows start above degree 4. The input and source hashes and per-system witnesses are in `audit-split-ffd.json`. `audit_split_m5k3_inputs.py` checked the two frozen m=5,k=3 VM input files against their frozen curve/target identity records and independently regenerated generators; it certified the same FFD value in `audit-split-m5k3-ffd.json`. The frozen input and identity files are saved here for replay; their differing time and row limits do not enter the polynomial certificate.

The split m=5,k=3 degree-7 closures exclude 1 for both primes, certifying LFD at least 8. The degree-8 F4 trace replays below refute both frozen input systems, so their LFD values are exactly 8. Both D8 FIFO continuation producers stopped at their time caps without a unit; independent indexed and dense replays passed for every saved derivation (ranks 116,718 and 116,815), but neither prefix is closed. ## Reproduce the audit

From this directory in the paper checkout, run the six `audit_*.py` scripts, then `python3 grid_status.py`. The audit scripts verify frozen input and source hashes and rebuild the summary receipts; `grid_status.py` must report `complete` with 21, 6, and 17 cells and no missing entries. The F4 trace files and exact Linux binary are retained so both degree-8 upper-bound traces can be replayed in their recorded engine. The binary and fixed-basis FFD producers are retained as source, but the saved FFD receipts should be audited before rerunning producers because the producers require their output files to be absent.
