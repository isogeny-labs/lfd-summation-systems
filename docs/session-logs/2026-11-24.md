## ECC2K-130 window question part 2: Jacobian necessary-condition tests

### What was done
- Owner said to continue. Installed PARI/GP 2.15.4 via apt (no environment change). Tested the Weil
  factor A against the computable Jacobian necessary conditions: virtual point counts #C(F_2^k) and
  Howe-Lauter closed-place counts a_d, both from P_A. Script:

### Results (exact, cross-checked)
- #C(F_2)=2, #C(F_4)=2, #C(F_8)=14, ...; all #C(F_2^k) >= 0 (min 2, k=1..1599).
- a_1=2,a_2=0,a_3=4,...; all closed-place counts a_d non-negative integers (min 0, d=1..400).
- => A passes every cheap decisive Jacobian test; no zeta-function obstruction. Window stays OPEN
  (necessary not sufficient); A is not ruled out.

### Errors (caught and fixed)
- First Newton's-identity loop ran i=1..k instead of i=1..k-1, double-counting the e_k term and
  producing spurious NEGATIVE #C(F_2)=-258, #C(F_4)=-518. Caught via disagreement with the exact
  structural power-sum formula (s_k^A = -s_k^E for 131 nmid k). After the fix both methods agree for
  k=1..1599 and all counts are non-negative. Important near-miss: the buggy version would have
  falsely "proved" A is not a Jacobian.
