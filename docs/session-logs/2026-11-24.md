## ECC2K-130 window question part 2: Jacobian necessary-condition tests

### What was done
- Owner said to continue. Installed PARI/GP 2.15.4 via apt (no environment change). Tested the Weil
  factor A against the computable Jacobian necessary conditions: virtual point counts #C(F_2^k) and
  Howe-Lauter closed-place counts a_d, both from P_A. Script:
  experiments/ecc2k130-weil-factor/jacobian_tests.py. Updated docs/ecc2k130-weil-factor-A.md. PR TBD.

### Results (exact, cross-checked)
- #C(F_2)=2, #C(F_4)=2, #C(F_8)=14, ...; all #C(F_2^k) >= 0 (min 2, k=1..1599).
- a_1=2,a_2=0,a_3=4,...; all closed-place counts a_d non-negative integers (min 0, d=1..400).
- => A passes every cheap decisive Jacobian test; no zeta-function obstruction. Window stays OPEN
  (necessary not sufficient); A is not ruled out.

### Errors (caught and fixed)
- First Newton's-identity loop ran i=1..k instead of i=1..k-1, double-counting the e_k term and
  producing spurious NEGATIVE #C(F_2)=-258, #C(F_4)=-518. Caught via disagreement with the exact
  structural power-sum formula (s_k^A = -s_k^E for 131 nmid k). After the fix both methods agree for
  k=1..1599 and all counts are non-negative. Important near-miss: the buggy version would have
  falsely "proved" A is not a Jacobian.

## ECC2K-130: index-calculus cost model for the hypothetical genus-130 Jacobian

### What was done
- Owner said continue. Computed the exact smooth-divisor index-calculus cost for the hypothetical
  genus-130 curve carrying A, from A's true place counts a_d and effective-divisor counts B_m (all
  from P_A). Script: experiments/ecc2k130-weil-factor/ic_cost_model.py.

### Results (exact counts, model cost)
- B_m >= 0 for m=0..130 (consistency check).
- Optimal smoothness bound t=24, |FB| ~ 1.46e6: relation collection ~2^33 trials (~2^47 ops with a
  conservative g^2 ~2^14 per-trial smoothness-test factor), sparse linear algebra ~2^27.5.
- Conditional on A ~ Jac(C): ECDLP cost ~2^33-2^47, i.e. 14-28 bits below rho (~2^61). Refines the
  crypto-notes 2^37.17 figure with exact counts.

### Decisions / caveats
- CM-type cyclic-cover ruling-out was deprioritized: it only addresses one construction (cyclic covers)
  and is error-prone; the cost model is reliable and makes the stakes exact, which is higher value.
- Hard caveats recorded: conditional on the open window question; needs explicit curve + evaluatable
  isogeny even if A~Jac; this is a cost model, not a validated run.
